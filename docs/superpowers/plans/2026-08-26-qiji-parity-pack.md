# 骑迹复刻包 — 实现记录

- 日期：2026-08-26
- 背景：调研竞品「骑迹」（App Store id6479238547，手动码表工具）后，选择性复刻其核心功能；
  被动记录 / 手表 / 健康 / 导航仍是我们的差异化，不动。
- 状态：已实现（域测试 7/7 绿；全 app 类型检查零错误；模拟器回归与真机验证待用户侧 Xcode 执行）

## 已实现

1. **海拔链路**（前置）：`GPSSample.altitude`（可选，默认 nil）→ `RoutePointDTO.altitude`
   （旧 JSON 无键解码为 nil，无迁移）→ LiveRideTracker / ManualRideSession 采集
   `verticalAccuracy >= 0` 时带海拔。域新增 `elevationGainMeters`（滞回阈值 10 米防
   GPS 垂直噪声虚报），详情页展示「累计爬升」。
2. **速度曲线**：详情页 Charts 面积+线图，轨迹逐点速度（过滤 <0 与 ≥30 m/s 异常），
   降采样 ≤120 点。
3. **分享卡片**：`RideShareCard` 360×480 视图（轨迹剪影 Canvas 画线，非地图截图——
   无网络依赖、不暴露街道、等比投影带纬度余弦校正）+ ImageRenderer 3x 出图 +
   UIActivityViewController 分享；详情页工具栏入口。
4. **停等自动暂停**（手动骑行）：速度 <1.0 m/s 持续 5 秒冻结计时（GPS 不停，检测恢复），
   ≥1.6 m/s 自动续；速度无效（<0）不参与判定；不计暂停期间距离/轨迹。
5. **超速提醒**：设置里选阈值（关/25/30/35/40 km/h，`overspeedAlertKmh`，0=关），
   手动骑行达到阈值警示震动（10 秒防抖）；码表页超速变红。
6. **码表模式**：手动骑行页工具栏切换，当前时速大字 + 四格数据；骑行中屏幕常亮
   （`isIdleTimerDisabled`）。
7. **轨迹合并**：`RideMerging`（8 例单测）——同类型、间隔 ≤2h 可合并；时长为两段之和
   （间隙不计）、距离/卡路里求和、心率按时长加权、轨迹按时间拼接、源不同记 merged、
   清 isAutoDetected；健康删旧 workout 后按写回开关重写。时间线长按行出「与 HH:mm
   的记录合并」。

## 明确不做（调研结论）

- 多轨迹叠加对比（严肃训练党需求）、真水印相机（分享卡片替代）、独立指南针、
  背景/字体换肤、轨迹回放动画（缓做）。
